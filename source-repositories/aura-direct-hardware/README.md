# Aura Direct Hardware

An open, source-led field for taking the Aura of Intelligence towards local-first hardware, custom silicon and a decentralised global compute commons: XR wearables, food computers, industrial processing, place-aware infrastructure and an expanding Space Web.

This public-interest research site invites parallel work across simulation, agent design, software, FPGA, small-batch silicon and deployment, while naming the interfaces where experiments affect other people or shared systems.

[Explore the live Aura Direct Hardware site](https://auraofintelligence.github.io/aura-direct-hardware/).

## Status and evidence boundary

The site keeps current engineering references, feasible research pathways and speculative design visibly separate. It does not claim that an Aura chip, core, SoC, foundry run, worldwide compute commons or Space Web has already been delivered. Hardware, health, energy, radio, nuclear, aerospace and shared-infrastructure work would each need the relevant technical proof, rights, regulation and human review before real deployment.
